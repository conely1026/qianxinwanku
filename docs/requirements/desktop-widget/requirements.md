## 目标

在保留网页版的前提下，提供一个适合长期停留在 Windows 桌面的轻量挂件。用户不需要打开完整页面，就能看到今天的下班倒计时、工作进度、实时收入和离席状态；需要设置、换算、日历或备份时，再进入展开面板。

桌面版不是“把网页装进一个普通窗口”。第一版需要先把高频信息压缩为挂件，把低频功能留在展开面板。

## 用户场景

- 上班后把挂件放在屏幕边缘，持续查看距离下班还有多久。
- 凌晨下班时，仍按当前班次显示倒计时和收入，不在零点错误重置。
- 临时离席时直接在挂件开始或结束计时；严格到下一次上班后才重置当日离席数据。
- 需要计算消费对应的工作时间、检查日历或改参数时，打开展开面板。
- 更新版本后，在不打断计时的前提下看到“有新功能”的提示，并可左右切换多条更新。

## 第一版信息架构

### 紧凑挂件

紧凑态只放每天反复查看或操作的内容：

- 当前工作状态：未上班、工作中、午休、已下班或休息日。
- 下班倒计时或下一次上班时间。
- 今日班次进度和实时税前收入。
- 离席计时的开始、结束和当前累计。
- 展开入口、锁定状态和新版本提示。

计时只跟随当前需要计时的状态：工作中和午休中显示剩余时间，离席中显示已离席时间；上班前、已下班和休息日不显示 `00:00` 或下一班次倒计时。

第一版默认使用“极简胶囊加展开面板”。两套常驻皮肤固定为 `360 × 76 DIP`。紧凑态只有显式按钮触发操作：展开只点展开按钮，离席只点离席按钮；倒计时、收入、小猫和其余空白区域全部作为窗口拖动区，不再隐式展开。

桌面版同时支持内置“小猫上班”皮肤。皮肤只替换紧凑态的视觉和状态动作，不改变按钮能力、展开面板、业务数据或更新时间规则。工作中表现为按 `Ctrl / S` 键盘，离席表现为滑滑板，午休表现为趴在键盘上睡觉，下班开小车，休息日坐在游戏椅上。

### 展开面板

展开态承接网页版现有功能：

- 今日详情。
- 消费换算和预设管理。
- 工作日历。
- 个人数据、导入导出和设置。
- 发布记录轮播。

展开态可以复用现有 React 功能界面，但不要求与网页版底部导航保持同一种窗口结构。

## 窗口与交互

- 窗口默认无边框，可拖动，并记住位置和缩放比例。
- 恢复窗口位置时必须适配多显示器变化，保证挂件不会落在可见区域之外。
- 支持置顶且默认开启；用户可在展开面板中关闭。
- 支持锁定位置。若提供鼠标穿透，必须同时提供托盘菜单或全局快捷键恢复交互，不能让用户失去控制入口。
- 托盘菜单至少包含：显示挂件、解除位置锁定和退出。
- 关闭按钮隐藏到托盘；彻底退出只从托盘菜单执行。
- 应用只允许运行一个实例；再次启动时唤起现有窗口。
- 吸附屏幕边缘作为便携版验收后的增强项，不阻塞第一个可测试包。

## 数据与升级

- 工资参数、班次、离席状态、换算预设和发布记录阅读状态继续只保存在本机。
- 业务数据结构只能定义一次，网页版和桌面版共用相同的 schema、默认值和迁移函数。
- 网页浏览器的 `localStorage` 与桌面应用的存储空间默认不互通；第一版通过导出和导入迁移，不承诺自动读取浏览器数据。
- 升级桌面应用不得主动清空已有本地数据。需要变更字段时，先迁移再保存。
- 离席的自然日变化不能直接触发重置；重置点是上一班次结束之后的下一次实际上班开始。
- 发布提示按已读版本判断。存在多条未读时，打开同一个轮播弹窗，通过左右按钮切换，不使用“错过了 N 次更新”的提示。
- 皮肤、窗口位置、缩放、置顶和锁定属于桌面偏好，不进入 Web/Desktop 业务备份；导入业务备份不得改变这些偏好。

## 第一版范围

必须包含：

- Windows 紧凑挂件和展开面板。
- 现有今日、换算、日历、个人和设置能力可达。
- 拖动、位置持久化、多显示器边界修正、托盘和单实例。
- 置顶开关和安全的锁定恢复路径。
- 本地数据持久化、导入导出和版本迁移。
- 可生成便携版供真实 Windows 冷启动验证。
- 默认胶囊与小猫上班两套内置皮肤可切换，未知皮肤配置可安全回退默认胶囊。

暂不承诺：

- 云同步和账号系统。
- 自动读取各浏览器中的网页版数据。
- 跨平台 macOS 或 Linux 安装包。
- 自动更新服务、代码签名和正式安装器；这些在便携版验收后另立发布任务。

## 验收标准

- 挂件冷启动后 2 秒内可交互，不显示完整网页白屏或浏览器导航框架。
- 00:00 之后的跨日班次倒计时、收入和离席状态与网页版规则一致。
- 拖动挂件后退出并重启，位置和缩放得到恢复；拔掉副屏后仍能回到可见区域。
- 锁定或鼠标穿透后，用户可通过已声明的托盘或快捷键恢复操作。
- Web 与 Desktop 对同一份业务状态样例得到相同的时间、收入、换算和重置结果。
- 覆盖安装或替换便携版可执行文件后，原有本地数据仍可读取。
- 网页版原有 GitHub Pages 构建、离线缓存和响应式页面不因桌面版而退化。
- 两套皮肤对同一业务状态显示相同的倒计时、收入、离席时间和可用动作；切换皮肤不重置计时或数据。

## 已确认的产品决策

- 默认紧凑形态使用极简胶囊加展开面板；小猫上班属于可选皮肤，不是第二套功能。
- 默认置顶，默认不锁定；锁定只禁止拖动，托盘保留解锁入口。
- 展开、离席和其他业务动作只由各自的显式按钮触发；紧凑挂件其余区域全部拖动窗口。右键打开窗口菜单，不定义双击业务动作。
- 隐藏到托盘不停止计时，真正退出只从托盘菜单执行。
- 鼠标穿透默认关闭；若后续提供，必须同时提供托盘和快捷键恢复路径。
- 首个便携包不以边缘吸附为门槛；后续若加入，必须可关闭且不做自动隐藏侧边栏。
