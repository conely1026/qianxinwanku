# 千薪万苦

一个把工资换算成正在流逝的时间的前端小工具。

## 功能

- 今日下班倒计时、班次进度与实时收入
- 消费金额换算为工作时间，可添加自己的项目
- 工作日历与休息日覆盖
- 带薪离席计时、耳机使用成本与年度工资轨迹
- 工作参数、本地备份导入导出
- localStorage 本机持久化 + Service Worker 离线应用缓存
- 响应式布局与 GitHub Pages 静态部署

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

所有个人数据仅保存在访问者自己的浏览器中，不会提交到服务器。
